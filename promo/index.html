Mounting positions

手机放哪儿，都能当仪表。

T-Dash 不挑安装位。方向盘左侧可横可竖，传统仪表位一般是横屏，平放在 HUD 槽里，或夹到车机屏左上角——同一块仪表，四种顺手的摆法。

驾驶位视角 · 非实车比例鼠标停在某一项，图里对应位置会亮起
01
方向盘左侧 · 手机支架强烈推荐

尤其是固定于车门把手、空调出风口的手机支架：驾驶员左右都可以看到车速，更安全。可横可竖；注意别挡左前视野、转向灯拨杆和 A 柱。

02
方向盘后 · 传统仪表位

一般是横屏。手机立在原车仪表前，读数正对视线。先确认不遮挡原车仪表、转向柱与拨杆，手机也不能碰到方向盘。

03
HUD 位 · 附加 HUD

手机平放在仪表台 HUD 凹槽，靠前风挡反射读数。夜间更清楚，白天亮度有限；别加贴膜挡视线。

04
车机屏左上角 · 夹装

夹在车机屏幕左上角，导航与 T-Dash 同屏。注意别挡住车机触控、出风口和屏幕散热。

仅为摆放示意，不构成安装建议：任何摆法都不得遮挡视线、方向盘、安全气囊或车机触控；行驶中不要调整手机；以车辆说明书和当地法规为准。

Why it feels instant

极致低延迟：行驶中，只问车一件事。

一块仪表只有一件要紧事：读数别滞后。行驶全程只发一条高频请求——vehicle_data(DRIVE)；车速、功率、里程、档位都装在同一条响应里，一次拿全。下一轮按上一轮的实测往返 +60 ms 排，最快 250 ms 一刷。

充电、空调、车外温度这些驻车数据，行驶中一条都不发；轨迹用手机自己的 GPS，不占蓝牙带宽。所有读数同一时刻只允许一条在飞，慢读排队也拖不住车速。

锁车、开闭件这类命令走 VCSEC——整车睡着时也能直接应答，不会为了看一眼状态把车叫醒。

Security

安全设计：T-Dash 没有服务器。

T-Dash 是纯蓝牙应用：没有账号、没有遥测、没有云端，也不运营后端、API 端点或云同步。手机与车辆之间只有 BLE 直连——不存在集中存放车主数据的数据库，也没有可供开发者查询数据的管理后台。

首次启动时随机生成一把 P-256 钥匙。私钥用 AndroidKeyStore 的 AES-256-GCM 封装后存放，配对时只把公钥交给车；日志里只出现指纹末四位。

  • 01无服务器，无后台：开发者没有你的数据，也没有可以远程查询数据的入口。
  • 02每台设备独立生成，不预置、不复用，换机不会带走旧钥匙。
  • 03解封失败绝不静默换钥匙，要你在设置里显式确认才重新生成。
  • 04车辆链路纯 BLE；联网只发生在统计页地图瓦片、定位解析和可选的高德天气（默认关），由手机直发高德/OSM，不经过 T-Dash，也没有遥测上传。

Open source software · open protocol

软件开源，使用免费。

T-Dash 本身是 Apache-2.0 开源软件：源码可读，蓝牙链路和密钥处理都能自己审计，也可以按自己的车和习惯改功能；没有月费，没有高级版，也没有插在中间收费的服务器。欢迎提 issue、PR 一起共建。

底层命令遵循特斯拉官方开源仓库 vehicle-command 的公开协议定义，手机与车直接对话——不经过任何第三方服务。

First run

三步，手机连上车机。

不需要 Tesla 开发者账号，也不需要填任何账号密码。

STEP 01

站到车旁

打开手机蓝牙，保持约 5 米内。输入 17 位 VIN，扫描并连接车辆。

STEP 02

发一次配对请求

点「发送配对请求」，把 NFC 钥匙卡贴在中控读取区。

STEP 03

车机上点确认

中控屏弹出确认框后点「确认」，钥匙就留在本机了；之后打开 App 自动重连。

适用边界：控制与仪表依赖蓝牙，远程能力不在这一版里。车机屏幕本身不受第三方 App 控制；这里的仪表是手机侧的数字仪表。本页按当前版本的实际排版重绘，视频帧与地图为示意底图。

Notes

说明

开发本软件使用 Qoder 辅助开发。

协议车辆通信基于 Tesla 开放的 vehicle-command 协议定义；手机与车直连，不经过第三方服务。

地图能力定位解析与天气来自高德地图开放平台，需自行前往高德开放平台申请个人 API（Web 服务 Key）。Key 只存本机，请求由手机直接发往高德，请自行保管；个人 Key 存在被限流或封禁的可能。统计页底图走高德公开栅格瓦片（非开放平台接口），仅限个人非商业使用；如高德调整授权会更换底图源。

无服务器T-Dash 没有服务器：没有账号、遥测和云同步，也没有可供开发者查询数据的后台。开发者和任何服务器都拿不到你的私钥与本机数据。

联网与数据私钥、轨迹、取证照片和个人信息只存本机。联网只发生在统计页底图、定位解析和天气；由手机直发高德或 OpenStreetMap（未配置 Key 时定位解析退回 OSM），不经过 T-Dash，发出的只有瓦片编号、坐标或城市编码，不含 VIN、车速或轨迹文件。

使用风险本软件按「原样」免费提供，不提供任何担保。驾驶中请勿操作手机；车辆控制结果以车辆本身为准，使用风险由使用者自行承担。

测试范围本软件由个人开发者开发与维护。受成本限制，只在个人所有的 Tesla Model 3 焕新版和 vivo X100 上做过实车测试；在其他车型或机型上遇到问题，欢迎提 Issue，也可以自行修改源码修复。
